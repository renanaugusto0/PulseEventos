# 🎉 Pulse Eventos 🎭

Bem-vindo ao **Pulse Eventos**, o projeto que celebra a vibração e a energia do entretenimento! Este é um dos trabalhos desenvolvidos durante o curso de **Desenvolvimento Multiplataforma** do Governo de SP.

## 🌟 Sobre o Projeto

O **Pulse Eventos** é uma página web dedicada a promover eventos de música, teatro e dança, oferecendo uma experiência moderna e envolvente para os usuários. Aqui, o foco está em:

- **Interatividade:** Um design responsivo e uma barra de navegação dinâmica.
- **Estilo:** Uma interface vibrante e moderna, destacada por uma paleta de cores impactante.
- **Conteúdo:** Informações detalhadas sobre eventos em uma estrutura bem organizada.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura da página.
- **CSS3:** Estilo visual e responsividade.
- **JavaScript:** Comportamentos dinâmicos, como menu fixo ao rolar.

## 🚀 Funcionalidades

- Navegação intuitiva entre seções.
- Layout adaptável para diferentes dispositivos.
- Tabela informativa com detalhes de eventos e preços.
